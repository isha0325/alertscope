# Resource metadata

`resource.json` describes the supported live-alert intent to hyperDart. Its query
examples cover all six required searches. `entities.collections` requests city,
state and country context using the host resource convention.

The component primarily reads the documented `searchData.entities[].entityInfo.geo`
shape. `queryProps.query` and an entity array are accepted as fallback context;
no alert content is generated by the resource schema. Hazard/product filtering
is deterministic in `intent.js`.

The official host resolves location entities; the local playground only supplies
explicit example entities. It does not implement a second geocoding service.
